## 🛠️ ¿Qué hago? (Perfil Híbrido)

Combino la lógica del desarrollo de software y la ciencia de datos con la estrategia comercial y el marketing digital:

- **Desarrollo Web & Landings:** Creación de interfaces modernas, mobile-first, optimizadas para velocidad de carga y conversión de usuarios (HTML5, CSS3, JavaScript, WordPress y E-commerce).
- **Paid Media & Growth:** Estructuración y optimización de campañas publicitarias en Meta Ads orientadas a métricas reales (CTR, CPL, ROAS) y control de fatiga publicitaria.
- **Datos & CRM:** Integración técnica de flujos de conversión (Píxel, API de Conversiones) y conexión de leads hacia plataformas comerciales (Pilot CRM).
